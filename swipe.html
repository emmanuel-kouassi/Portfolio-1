Swipe — Site d'achat de formation

Création de l’identité visuelle et du site d’une marque de bonnets en satin.

1. Contexte du projet

Swipe est un projet universitaire de plateforme e-commerce spécialisée dans la vente de formations en ligne dédiées au développement web. L’objectif était de concevoir un écosystème complet permettant aux étudiants et passionnés de tech d'acquérir des compétences techniques (HTML/CSS, JavaScript, React, etc.) via un parcours d'apprentissage fluide. Le projet met l'accent sur une interface moderne et épurée, dont le tunnel d'achat est entièrement sécurisé par l'intégration de Stripe.

2. Outils utilisés

  • React (TSX) : (front-end)
  • Spring Boot : (API, Base de donnée)
  • Stripe API : (Paiement)
  • Docker Desktop : (Conteneurisation de l'application)
  • Render : (Hébergement du site et de l'API)
  • Aiven : (Déploiement cloud de l'API)

3. Difficultés rencontrées

  • la communication sécurisée entre le Front-end et les serveurs de paiement.
  • Assurer une synchronisation parfaite entre les modèles Java de l'API et la base de données Spring Boot.
  • Résolution des erreurs de configuration lors de l'hébergement de l'API sur Render (variables d'environnement, ports, accès DB).
  • Gestion des blocages et erreurs de connexion entre le développement local et l'API distante

4. Étapes de réalisation

  1. Modélisation de la BDD
  2. Développement de l'API (Back-end)
  3. Architecture Front-end
  4. Connexion du Front-end à l'API
  5. Intégration Stripe
  6. Test
  7. Hebergement
  8. Soutenance

5. Résultat & Bilan

Le projet Swipe a abouti à une plateforme e-commerce de formation parfaitement fonctionnelle, alliant la rigueur d'un back-end Spring Boot à la fluidité d'une interface React (TSX). Malgré les défis techniques liés à l'interconnexion des environnements et au déploiement via Docker sur Render et Aiven, l'objectif principal a été atteint : proposer un tunnel d'achat sécurisé et intuitif grâce à l'intégration de Stripe. Ce projet m'a permis de consolider mes compétences Full-stack et DevOps, tout en apprenant à gérer l'intégralité du cycle de vie d'une application web moderne, de la base de données jusqu'à la mise en production réelle.
