Lyceeapp — Application mobile de recensement

Création d'une application moblie de recensement de lycée de l'academie de creteil'.

1. Contexte du projet

Ce projet universitaire consiste en la création d'une application web dynamique permettant de recenser des lycées de l'académie de Créteil par plusieurs categories . L’objectif était de concevoir un outil d'aide à l'orientation fluide, offrant une recherche multicritères (Stat des lycée de creteil, Top lycée pro, mails academie de creteil, MAJ 2026) pour faciliter l'accès à l'information des élèves et des parents. Le projet met l'accent sur la manipulation de données géographiques et la clarté de l'interface utilisateur.

2. Outils utilisés

  • React native : (front-end)
  • API : (Information de tout les lyc"e de creteil)
  • Expo Go : (Pour tester sur le mobile en local)

3. Difficultés rencontrées

  • Affichage sur expo go
  • Comprehension des routeurs pour pemttre d'aller sur une autre page

4. Étapes de réalisation

  1. Codage
  2. lien avec l'api
  3. Test sur Expo Go
  4. Hebergement

5. Résultat & Bilan

Le projet a abouti à une application fluide et parfaitement fonctionnelle pour le recensement des lycées. Sa mise en œuvre, bien que simple, a permis de valider la maîtrise du cycle Full-stack (React / API). Ce projet constitue une base solide et réussie, confirmant ma capacité à structurer des données d'API pour les rendre accessibles. Fort de cette expérience, je souhaite désormais m'orienter vers des architectures plus complexes .
