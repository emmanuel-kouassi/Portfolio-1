Projet AC2FL

Site complet développé en Bootstrap – Analyse, outils, difficultés, process.

1. Contexte du projet

J’ai réalisé le site complet d’AC2FL uniquement avec Bootstrap 5. Le but était d’obtenir un site moderne, responsive, et facile à maintenir. Ce projet m'a demandé d’apprendre à maîtriser la grille, les composants et les possibilités de personnalisation de Bootstrap.

2. Outils utilisés

  • HTML / CSS
  • Bootstrap 5
  • JavaScript (interactions légères)
  • VS Code

3. Difficultés rencontrées

  • Compréhension du système de grille Bootstrap
  • Rendre le site 100% responsive sur mobile & tablette
  • Personnaliser les composants sans casser le style natif
  • Gérer les marges, paddings et alignements
  • Corriger les conflits entre Bootstrap et mon CSS personnalisé

4. Étapes de réalisation

  1. Analyse du besoin
  2. Création de la structure HTML
  3. Intégration Bootstrap (layout + composants)
  4. Personnalisation CSS
  5. Implémentation des interactions JavaScript
  6. Tests de responsivité
  7. Mise en ligne sur Vercel

5. Résultat & Bilan

Ce projet m’a permis d’améliorer ma rapidité d’intégration et ma compréhension du framework Bootstrap. J’ai aussi appris à gérer une structure complexe et à résoudre des problèmes de responsivité.
