Site — Cité des Milles-Mille

Projet universitaire : UX/UI + développement responsive sous Bootstrap.

1. Contexte du projet

L’objectif était de concevoir et développer un site moderne pour présenter la Cité des Milles-Mille. Le site devait être attractif, responsive, et mettre en avant les informations principales d’une manière claire, en s'appuyant sur une identité visuelle jeune et dynamique.

2. Outils utilisés

  • HTML / CSS
  • Bootstrap 5
  • JavaScript
  • Figma (pour les inspirations UI)
  • VS Code

3. Difficultés rencontrées

  • Créer une identité visuelle cohérente avec un sujet sensible (représenter une cité sans stéréotypes)
  • Gérer le design responsive pour éviter les bugs mobile
  • Optimiser les images pour éviter un temps de chargement trop long
  • Uniformiser les sections (cartes, textes, header) dans une DA moderne
  • Maintenir un bon équilibre entre sobriété et dynamisme visuel

4. Étapes de réalisation

  1. Analyse du sujet & intentions visuelles
  2. Recherche d’inspiration (sites urbains, portfolio modernes)
  3. Création de la structure HTML
  4. Intégration Bootstrap (grille + composants)
  5. Ajout d’un design moderne (couleurs, arrondis, images fortes)
  6. Test mobile + optimisation
  7. Mise en ligne sur Vercel

5. Résultat & Bilan

Le site final est moderne, immersif, et accessible. Ce projet m’a appris à trouver un ton visuel neutre mais esthétique, à travailler une narrative visuelle et à renforcer ma maîtrise de Bootstrap dans une structure complète.
